N = RL

Multiply independent choices

If each of L positions can independently contain any of R characters, the total number of strings is R raised to L.

EXAMPLE10⁴ = 10,000 four-digit sequences
nP r = n! / (n − r)!

Order matters

When digits cannot repeat, each choice reduces the options for the next position. PIN order creates distinct sequences.

EXAMPLE10P3 = 10 × 9 × 8 = 720

Estimate exhaustive search

Divide search-space size N by hypothetical guesses per second G. Average exhaustive-search time is approximately half of worst case.
